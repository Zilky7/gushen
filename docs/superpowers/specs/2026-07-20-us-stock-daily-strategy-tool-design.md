# 美股日线策略研究工具：设计规格

## 目标与边界

构建个人私有 Web 工具。用户输入美股代码并点击分析，系统基于日线数据输出多头和空头候选策略；重点展示多头。每项策略给出加仓区、第一和第二止盈区、失效线、风险等级和可追溯理由。

首版不连接券商、不下单、不自动盯盘、不进行模拟盘交易执行。结论是研究辅助，不是投资建议。

## 数据与模型

- 价格和成交量：yfinance，无需 API Key；按需获取日线 OHLCV，缓存结果并展示来源和更新时间。
- 大模型：从 `.env` 读取 OpenAI 兼容接口的 base URL、API Key 和模型名；密钥不得写入代码、日志或版本库。
- 数据异常：数据不足、拉取失败或过期时，界面显示原因，不生成新的价格策略；可以明确标记缓存结果。

## 页面和交互

采用 Finviz 式深色、图表优先布局：

1. 搜索股票代码并点击分析。
2. 主区域显示日 K、成交量、SMA20/50/200、自动识别的支撑/压力区，以及加仓、止盈、失效线。
3. 图表下方显示策略卡：主策略突出，另一个方向作为候选或“无有效机会”。
4. 策略卡包含方向、加仓区、止盈一、止盈二、失效线、策略匹配度、条件和理由。
5. 保存分析记录，允许回看当时的数据时间、策略版本、计算结果和 LLM 解释。

前端使用 React、TypeScript 和 Lightweight Charts；后端使用 FastAPI/Python；SQLite 保存缓存、分析记录、策略版本和回测结果。首版作为模块化单体部署。

## 决策引擎

引擎以可配置、可回测的规则生成价格；LLM 不得发明或修改当前分析中的价格。

### 基础特征

- SMA20、SMA50、SMA200；SMA50 的 10 日斜率。
- Wilder ATR(14)。
- 20 日平均成交量。
- 枢轴高低点：某日高/低价分别高/低于其前后各 3 个交易日。
- 价格区：将相距不超过 `max(0.8 × ATR14, 股价 × 1%)` 的枢轴聚合；触碰次数和近期性决定强度。

### 趋势与候选模板

多头趋势使用 `close > SMA50`、`SMA20 > SMA50`、`SMA50 斜率 > 0`，且在 SMA200 上方额外加分；空头为镜像条件。

生成四个候选：多头回踩、多头突破、空头反弹失败、空头跌破。多头回踩要求趋势向上且价格进入支撑/均线共振区，出现重新走强的收盘确认；多头突破要求收盘高于压力区上沿至少 `0.1 × ATR`，且成交量不低于 20 日均量的 `1.2 倍`。空头条件镜像处理。

评分为：趋势 35%、关键位质量 30%、确认信号 20%、风险收益比 15%。该分数表示策略匹配度，而非上涨或下跌概率。

### 价格输出

- 加仓：输出价格区间和中心线，而不是虚假的精确单价。
- 失效线：多头为支撑区下沿减 `1 × ATR`；空头为压力区上沿加 `1 × ATR`。
- 第一目标：下一层有效压力（空头为支撑）；若风险收益空间不足，使用 `1.5R`。
- 第二目标：下一层更远关键位；缺失时使用 `2.5R`。
- 若第一目标的风险收益比低于 1.5，候选标记为“无有效机会”。

`R` 等于加仓中心线和失效线的价格距离。

## LLM 角色与策略迭代

LLM 接收策略引擎输出的结构化事实，只返回符合 schema 的理由、风险和触发条件。它不能修改当前价格线。

离线优化允许 LLM 在受限参数中提出变更，例如均线周期、ATR 倍数、支撑区聚合阈值、成交量确认阈值和评分权重。每次提议创建不可变策略版本，保留参数差异、理由和评价指标。

## 历史优化与验证

严格隔离未来样本：

1. 使用 2023-01-01 至 2025-12-31 的日线进行规则研究和参数优化。
2. 在该阶段内部以 2023-2024 训练基础规则、2025 验证候选参数，或采用等价的滚动时间切分。
3. 锁定策略版本后，使用 2026-01-01 至 2026-06-30 作为完全隔离的样本外回测集。LLM 优化阶段不得访问该时间段的 K 线或结果。
4. 比较基准与优化版本的多空收益、胜率、最大回撤、平均盈亏比、交易次数、止盈命中率和失效触发率。优化版未在样本外保持优势则不采用。

首版不会自动替换正式策略。优化候选和报告可供用户审阅。

## 测试与验收

- 对 SMA、ATR、枢轴点、价格区、止盈和失效计算使用固定样本单元测试。
- 对固定 K 线样本做策略回归测试，保证同一策略版本的计算结果稳定。
- 测试 yfinance 数据失败、数据不足、缓存降级和日期缺口。
- 测试 LLM JSON schema 和事实一致性：所有输出价格必须可追溯到引擎计算结果。
- 前端覆盖分析中、有效策略、无有效机会、数据失败和历史记录查看状态。

## 非目标

- 券商账户连接、模拟盘执行、自动下单、自动价格提醒和实时盯盘。
- 分钟级/小时级策略。
- 把 LLM 生成的自然语言直接视为价格或交易指令。
